# ☕ Camper Cafe Menu

Proyecto del curso de **Responsive Web Design** de freeCodeCamp. Menú simple para una cafetería hecho solo con HTML y CSS.

🔗 **Link** https://maurigallero.github.io/Menu_coffee_shop/

### 🚀 Demo
Podés ver el proyecto clonando el repo y abriendo `index.html`, o si activás GitHub Pages va a quedar en:
`https://maurigallero.github.io/Menu_coffee_shop/`

### 🛠️ Tecnologías usadas
- HTML5
- CSS3
    - `background-image`
    - Box Model (margin, padding)
    - Selectores de clase, tipo y pseudo-clases (`:hover`, `:visited`)
    - `display: inline-block`

### 📚 Lo que practiqué
- Centrar elementos y crear un layout tipo tarjeta con `.menu`
- Alinear precios y sabores en la misma línea
- Dar estilo a imágenes, líneas `<hr>` y footer
- Usar fuentes y estilos para simular un menú real
